# LOVE SCAN · 감정 방사선 촬영실

NPC가 PC에게 품은 애정을 표층과 심층으로 나누어 촬영하는 OOC 결과 뷰어 — 빌드 없는 HTML/CSS/JavaScript.

**https://yuuuulll35.github.io/love-scan/**

AI 채팅에서 OOC로 받은 스캔 결과를 넣으면 성분 비율이 3D 표본의 형태가 되고, 심박수가 표본의 맥박이 된다. 표층 성분은 바깥 막의 돌기로, 심층 성분은 안쪽에서 도는 핵으로 그려진다.

## 표본이 만들어지는 규칙

표본의 바탕은 구와 하트 사이의 어느 형태이고, 답의 항목들이 그 위에 겹쳐서 모양을 바꾼다.

| 답의 항목 | 표본에서 |
|---|---|
| 표층 색 · 심층 색 | 표층 색은 표본의 막과 화면의 메인 컬러, 심층 색은 안쪽 핵과 심층 관련 표시의 색. 두 색이 너무 비슷하면 심층 색의 색조를 비킨다 |
| 결정화율 | 바탕 윤곽. 0%는 구, 100%는 하트. 높을수록 표층 돌기가 낮아져 하트가 또렷해진다 |
| 표층 성분 | 바깥 막의 돌기. 개수 = 성분 수, 높이와 폭 = 비율 |
| 심층 성분 | 안쪽 핵. 가장 큰 성분이 중심 핵, 나머지는 공전 핵 |
| 심층 주성분 비율 | 클수록 중심 핵이 커지고 막을 한쪽으로 밀어내 일그러뜨린다. 밀린 부분은 심박에 맞춰 더 크게 뛴다 |
| 경도 | 막을 짜는 방식. 1~3은 나선, 4~7은 고리, 8~10은 격자이며 7 이상은 표면이 계단처럼 각진다 |
| 투과율 | 막의 농도. 낮을수록 점이 굵고 빽빽해 속이 덜 비친다 |
| 공명 | 막 표면의 정상파 무늬. 주파수가 파문의 마디 수와 진폭을 정한다 |
| 나이테 | 안쪽으로 겹친 막의 수(1~6겹) |
| 자기장 | 표본 바깥의 선. 인력은 극에서 극으로 휘는 자기력선, 척력은 바깥으로 뻗는 방사선, 구속은 표본을 에워싼 궤도 고리. 세기가 선의 수를 정한다. 전체 보기에서만 보인다 |
| 반감기 | 짧을수록 입자가 표본 바깥으로 흩어진다 |
| 균열 | 막이 갈라진 틈. 사건 하나에 금 하나(최대 5개) |
| 원소 | 이 감정을 이루는 실제 원소 3~5개와 비율. 원자번호와 원자량은 주기율표 값(주요 원소 52종)으로 사이트가 채운다. 표본 형태에는 쓰지 않는다 |
| 이물(삼킨 것) | 표본 안쪽에 하얗게 찍히는 물체. 이름에 따라 반지, 열쇠, 편지, 파편 모양(최대 4개) |
| 위험 등급 | 높을수록 막에 가시가 돋는다(안정은 가시 없음, 최고 위험은 가시 42개) |
| 애정 질량 | 클수록 점 밀도가 높아진다. 그램·킬로그램·톤·태양질량(M☉) 등의 단위를 킬로그램으로 바꿔 로그 눈금으로 잰다 |
| 심박 | 표본의 맥박. 누르고 있으면 접촉 시, 누르는 순간 최고 수치로 뛴다 |
| 이름과 성분 | 고유 번호(LS-XXXXXX)가 되어 돌기 방향, 파문 축, 가시와 금의 위치를 정한다 |

물성 항목(결정화율~반감기)이 없는 답은 고유 번호에서 뽑은 값으로 형태를 정하고, 판독지에는 그 항목을 표시하지 않는다.

판독지의 심전도는 같은 종이 속도로 실시간으로 그려지므로, BPM이 높을수록 박동이 촘촘하게 찍힌다. 최종 소견은 애정 질량과 위험 등급을 필름 배지 한 장으로 묶는다.

## 사용법

OOC는 답이 길어져 끊기지 않도록 세 번에 나눠 보낸다. ②와 ③은 같은 채팅에 이어서 보낸다.

1. **OOC ①**(감정 스캔): 표층 색, 심층 색, 요약, 표층·심층 성분
2. **OOC ②**(신체·물성 스캔): 심박, 시선, 증상, 특이 패턴, 물성 7항목
3. **OOC ③**(조성·최종 판독): 원소, 균열, 삼킨 것, 질량, 위험 등급, 소견

단계마다 **OOC 복사** → 채팅에 보내기 → 받은 답을 통째로 복사해 **답 붙여넣기**. 다 넣으면 **스캔 시작**.

답이 확인되면 입력 칸이 닫히고 단계 옆 상태가 **✓ 완료**로 바뀌며, 확인된 내용 요약과 **다시 넣기 / 지우기**가 나온다. 빠진 항목이 있으면 바로 알려 주고, OOC를 그대로 붙여 넣으면 답을 복사하라고 안내한다. 다음 단계는 앞 단계가 완료돼야 열린다. 브라우저가 클립보드 읽기를 막으면 **직접 붙여넣기**로 입력 칸을 연다. ①만으로도 스캔할 수 있지만, 그러면 빠진 단계의 항목이 판독지에서 빠지고 표본 형태 일부는 표본 번호에서 뽑은 값으로 정해진다.

결과 화면에서 표본을 끌면 돌아가고, 손을 대고 있는 동안 심박이 접촉 시 수치로 오른다. 마우스 휠, 두 손가락 벌리기, 오른쪽 **+ / −** 버튼으로 40~260% 확대·축소한다. 처음 크기는 65%이고, 표본을 두 번 누르거나 가운데 배율 숫자를 누르면 65%로 돌아온다.

판독지는 **개요 · 표층 · 심층 · 증상 · 원소 · 물성 · 균열·삼킨 것 · 소견** 탭으로 나뉜다. 탭과 표본이 서로 연결된다.
- 표층·심층·균열 탭을 열면 표본이 그 층으로 바뀐다.
- 표본 아래 **전체 / 표층 / 심층** 버튼을 누르면 해당 탭이 열린다.
- 표본의 라벨(S1, D1, F1 …)을 누르면 그 항목이 있는 탭이 열리고 항목이 강조된다. 판독지의 항목을 누르면 표본에서 그 부위가 밝아진다.

좁은 화면에서는 표본과 탭 바가 위에 고정되고 탭 내용만 스크롤되어, 표본을 보면서 내용을 읽을 수 있다.

표본 오른쪽의 **회전 GIF** 버튼을 누르면 하트 정면(가운데 시점)에서 시작해 9초에 걸쳐 천천히 한 바퀴 돌아 다시 정면으로 오는 반복 GIF(520×611, 약 4MB)를 저장한다. 도는 동안 표본은 심박에 맞춰 뛰고 스캔 하이라이트가 지나간다. 지금 보고 있는 층(전체·표층·심층)으로 찍히고, 이름·표본 번호·두 색·평상시 심박이 함께 들어간다.

버튼을 누르면 **커플링명 넣기**와 **LOVE SCAN만** 중에 고를 수 있다. 만드는 동안(약 10초)은 화면 전체가 어두워지고 진행률이 표시되며, 버벅이지 않도록 표본 회전과 심전도 애니메이션이 잠시 멈췄다가 저장이 끝나면 다시 움직인다. LOVE SCAN만을 고르면 상단의 NPC → PC 이름 자리에 LOVE SCAN이 들어간다.

**← 처음으로**를 누르면 단계별로 넣었던 OOC 답이 모두 비워진다.

처음 화면의 **예시로 보기**는 예시 답으로 바로 스캔한다. 마지막으로 스캔한 답은 브라우저(localStorage)에만 저장되어 **지난 스캔 다시 보기**로 돌아온다.

## OOC 답 형식

채팅에서 표로 바뀌지 않도록 `|` 구분 없이 한 항목 한 줄로 받는다.

OOC ① 감정 스캔:

```text
대상: NPC 이름 / PC 이름
표층 색: #RRGGBB · 색 이름 · 그 색인 이유
심층 색: #RRGGBB · 색 이름 · 그 색인 이유
요약: …
표층 1 [성분: 한글 이름 (English Name)] [비율: 41.2%] (설명: …)
심층 1 [성분: 한글 이름 (English Name)] [비율: 68.9%] (설명: …)
```

OOC ② 신체·물성 스캔:

```text
심박: 평상시 68 / 접촉 시 88 / 최고 135
시선: PC 8.7초 / 일반 2.1초
증상 1 [항목: 이름] [수치: 측정값] (설명: …)
특이 1 [항목: 이름] (설명: …)
결정화율: 46% · 근거
경도: 8 · 근거
투과율: 22% · 근거
공명: 392 Hz · 이 감정을 울리는 자극
자기장: 6.4 T · 인력 / 척력 / 구속 중 하나 · 근거
반감기: 11년 · 근거
나이테: 4겹 · 겹마다 쌓인 것
```

OOC ③ 조성·최종 판독:

```text
원소 1 [원소: 철 (Fe)] [비율: 41%] (설명: …)
균열 1 [항목: 금이 간 사건] (설명: …)
이물 1 [항목: 삼킨 말이나 물건] (설명: …)
질량: 수치와 단위 · 한 줄 비유
위험 등급: 안정 / 주의 / 경고 / 위험 / 최고 위험 중 하나
소견: …
```

- ①에서 표층과 심층 성분이 하나씩은 있어야 스캔할 수 있다. 나머지 항목은 없으면 그 부분만 빠진다.
- 여러 답을 한 칸에 몰아 넣어도 읽는다.
- `색상:` 한 줄만 오면 표층 색으로 쓴다. 색이 아예 없으면 표본 번호에서 고유한 색을 뽑아 캐릭터마다 다른 색이 나온다.
- 파서는 코드블록, `**굵게**`, 앞뒤 잡문을 허용한다.
- 형식 없이 받은 보고서(`### 2. 표층 감정 분석` 같은 제목 아래 `A. 이름 (English): 41.2%`와 설명 줄)도 읽는다. 이때 이름은 본문에서 따옴표로 가장 자주 불린 두 이름, 심박과 시선은 증상 설명 속 `BPM`과 `초` 수치에서 찾는다.
- 표본 번호(`LS-XXXXXX`)와 표본의 형태는 이름과 성분 비율에서 계산하므로 같은 답은 항상 같은 표본이 된다.

## 실행

저장소 루트를 그대로 정적 호스팅(GitHub Pages 등)한다. ES 모듈을 쓰므로 `file://`로는 열리지 않는다.

```bash
python3 -m http.server 8000
```

## 구조

```
index.html       화면 구조 (촬영 화면, 처음 화면, 판독지)
styles.css       디자인
js/app.js        화면 전환, 판독지 표시, 표본 주석, 저장
js/ooc.js        OOC 만들기와 AI 답 파서
js/specimen.js   WebGL 표본 (형태 생성, 스캔, 맥박)
js/monitor.js    심전도 모니터
js/data.js       위험 등급, 원소 표, 예시 답
```

표본은 라이브러리 없이 WebGL 점으로 그린다. WebGL을 쓸 수 없으면 2D 캔버스로 점 수를 줄여 그리고, 촬영 화면 위쪽에 작은 "간이 화면으로 보는 중" 표시를 띄운다. 누르면 원인에 맞는 안내가 펼쳐진다(그래픽 가속이 꺼진 경우 켜는 방법, 그래픽 드라이버와 맞지 않는 경우 그 사실). 기본 3만 개(좁은 화면은 1만 5천 개)에 애정 질량에 따라 0.55~1.35배를 곱한다. 화면 밖이나 백그라운드 탭에서는 그리기를 멈추고, 움직임 줄이기 설정에서는 회전·스캔·맥박 없이 정지 화면으로 보여 준다.

CSS와 JS 주소에는 `?v=` 버전이 붙어 있다. 배포할 때마다 `index.html`, `js/app.js`, `js/ooc.js`의 값을 같은 새 값으로 바꿔야 브라우저가 예전 파일을 캐시에서 꺼내 쓰지 않는다.

```bash
V=$(date -u +%Y%m%d%H%M); sed -i -E "s/\?v=[0-9]+/?v=$V/g" index.html js/app.js js/ooc.js
```
